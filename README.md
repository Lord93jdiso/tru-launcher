# TRU Launch — лаунчер Tomb Raider: Underworld

Мобильный Android-лаунчер для Tomb Raider: Underworld (ПК-версии, Windows) на базе
движка Winlator 11.2 (Wine + Box64). Своего интерфейса у Winlator здесь нет — остаются
только движок запуска, оверлей управления и HUD.

## Возможности
- Красивый арт-деко интерфейс: **ИГРАТЬ / НАСТРОЙКИ / ВЫХОД**
- При первом запуске: установка движка + выбор папки с игрой (tomb9.exe)
- Мобильное управление: стик + кнопки в раскладке TRU
  (Space = прыжок, E = взаимодействие, Q = гарпун, CapsLock = бросок, ЛКМ = огонь, ПКМ = оруж., R = смена оружия, Ctrl = присед, Shift = ускорение, F = фонарь, V = аптечка, Tab = КПК)
- Редактор управления: перетаскивание зон, масштаб, прозрачность, иконки
- Кастомные графические драйверы: Turnip (Adreno) / Vortek / Gladio / Zink / VirGL + импорт своих
- Пресеты производительности: Стабильность / **Средний (по умолчанию)** / Производительность
- HUD поверх игры: FPS + GPU + ОЗУ + CPU с переключением в реальном времени
- Плавающая кнопка меню над игрой (Полный экран / Управление / HUD / Выход)
- Языки: Русский / English

## Сборка
```bash
./gradlew :app:assembleDebug
```
APK появится в `app/build/outputs/apk/debug/`.

CI: `.github/workflows/build.yml` собирает APK в GitHub Actions и выкладывает артефактом.

## Установка
1. Установите APK.
2. Скопируйте папку с игрой (где `tomb9.exe`) в память телефона или на SD-карту.
3. Откройте лаунчер → ИГРАТЬ → выберите папку игры.
